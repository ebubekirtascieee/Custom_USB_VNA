# Custom_USB_VNA
Single-port VNA (Vector Network Analyzer) operating in the 600 MHz – 2.7 GHz range, featuring a custom-designed 4-layer PCB based on the Raspberry Pi Pico 2 MCU and a USB interface.
Superior performance for 900 MHz (ISM), 1090 MHz (ADS-B), 1.5 GHz (GPS), and 2.4 GHz (Wi-Fi/Bluetooth) metrology with minimal cost!
